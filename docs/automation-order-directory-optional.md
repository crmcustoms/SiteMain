# Заявки конструктора без синхронізації довідника

08.10.2026. Каталог є джерелом складу й оцінки проєкту. Довідник 21682 лише доповнює позицію посиланням.

Якщо варіанта немає або довідник недоступний, адаптер зберігає назву (59238), кількість 1 (59240) і нижню ціну проєкту (59242) в аналітиці 12322. Формула 59246 і сума задачі 112394 залишаються чинними. Знайдені записи отримують необов’язкове посилання 69452.

Після запису адаптер перевіряє окремі ключі позицій, назви, кількість, ціни, USD і підсумок перед Telegram. Невизначений запис не повторюється автоматично.

Схему crmcustomsua.planfix.ua та живий Swagger перевірено читанням. 12 адресних тестів адаптера пройшли; експорт 319 карток збігається з ядром. Реальних тестових заявок не надсилали.
