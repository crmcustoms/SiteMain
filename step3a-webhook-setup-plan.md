# Step 3A: Настройка GitHub Webhooks для автоматического деплоя

## Цель: 
Настроить автоматическое обновление сайта при изменении кода в GitHub

## Текущая конфигурация (по ответам администратора):
- Контейнер: sitemain-web-1
- Порт: 3000
- Git установлен на сервере
- Docker Compose используется
- SSL через Let's Encrypt (Caddy)
- Firewall: SSH/HTTP/HTTPS открыты

## План действий:

### 1. Создать webhook endpoint на сервере
- Создать простой HTTP endpoint для получения уведомлений от GitHub
- Endpoint будет запускать скрипт обновления

### 2. Настроить webhook в GitHub
- Добавить webhook в настройках репозитория
- Указать URL endpoint'а на сервере
- Настроить секрет для безопасности

### 3. Создать скрипт автоматического обновления
- Pull изменений из GitHub
- Пересобрать Docker контейнер
- Перезапустить сервис

### 4. Настроить безопасность
- Защитить webhook endpoint
- Использовать секретный токен
- Ограничить доступ по IP (если нужно)
