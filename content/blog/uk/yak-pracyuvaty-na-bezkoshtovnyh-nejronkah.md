Безкоштовних нейронок багато, але більшість мають такі ліміти, що це лише демо. Тут схема, на якій можна працювати щодня. Ви встановите **OpenCode** — безкоштовного агента для роботи з кодом і текстами, який вміє підключати різні моделі. Далі підключите безкоштовні моделі та дешевий резерв.

Інструкція для Windows, близько 20 хвилин. До кожного кроку є **готовий промт**: не хочете возитися руками — скопіюйте його й дайте своїй нейронці.

## Крок 1. Встановіть OpenCode

Потрібна саме консольна версія (CLI), а не окремий застосунок. Вона працює з безкоштовними моделями й дає змогу викликати OpenCode з іншого агента.

1. Встановіть [Git для Windows](https://git-scm.com/download/win). Разом із ним з'явиться програма **Git Bash**.
2. Відкрийте **Git Bash** (меню «Пуск» → Git Bash).
3. Вставте команду й натисніть Enter:

```bash
curl -fsSL https://opencode.ai/install | bash
```

4. Закрийте Git Bash і відкрийте його знову, щоб команда `opencode` стала доступна.
5. Перевірте установку: `opencode --version`. Має з'явитися номер версії.
6. Перейдіть у теку проєкту й запустіть OpenCode:

```bash
cd /c/projects/my-project
opencode
```

Відкриється робоче вікно в терміналі з полем для запиту. Хочете веб-інтерфейс у браузері? Замість `opencode` виконайте `opencode web`.

**Промт для нейронки:**

```text
Встанови на мій комп'ютер з Windows консольну версію OpenCode (CLI), не десктопний застосунок.
Кроки: перевір, чи є Git Bash; якщо немає, підкажи, як його встановити. Потім у Git Bash виконай:
curl -fsSL https://opencode.ai/install | bash
Після цього перевір команду opencode --version і скажи мені версію.
Якщо будь-який крок не вдався, покажи текст помилки й запропонуй виправлення. Роби по одному кроку й чекай мого підтвердження.
```

*Якщо ви не знаєте, як встановити цей сервіс, або не хочете морочитись — дайте вашій нейронці цей промт.*

## Крок 2. Оберіть безкоштовну модель

1. У вікні OpenCode введіть `/models`.
2. Знайдіть моделі з позначкою **free**, наприклад **DeepSeek V4.1 Flash Free**.
3. Оберіть її й напишіть тестовий запит: «Напиши список із трьох ідей для поста».

Безкоштовні моделі `opencode/...-free` працюють **без реєстрації й без ключа**: після установки вони вже є в списку `/models`. Ключ OpenCode потрібен лише для платних моделей.

Список безкоштовних моделей ведеться на [opencode.ai/docs/zen](https://opencode.ai/docs/zen/). Він змінюється, а деякі моделі безкоштовні лише на обмежений час. Для LongCat 2.5 Free документація прямо вказує ліміт 100 запитів на день. Для інших лімітів не вказано, тож тестуйте на своїх задачах.

**Промт для нейронки:**

```text
У мене встановлений OpenCode. Покажи мені список безкоштовних моделей командою:
opencode models | grep free
Обери з них одну для щоденної роботи (я хочу DeepSeek, якщо він є) і перевір, що вона відповідає:
opencode run -m opencode/deepseek-v4.1-flash-free "Напиши список із трьох ідей для поста"
Якщо такої моделі немає, візьми іншу з тими самими літерами free в назві і скажи мені, яку саме.
```

*Якщо ви не знаєте, як обрати модель, або не хочете морочитись — дайте вашій нейронці цей промт.*

## Крок 3. Додайте резерв через OpenRouter

Це страховка на випадок, коли безкоштовна модель відмовила через ліміт.

1. Зареєструйтесь на [openrouter.ai](https://openrouter.ai) і створіть ключ на сторінці [openrouter.ai/keys](https://openrouter.ai/keys).
2. Дайте ключу назву й **встановіть ліміт кредитів**.
3. Поповніть баланс на кілька доларів.
4. В OpenCode введіть `/connect`, оберіть **OpenRouter** і вставте ключ.
5. Введіть `/models` і знайдіть дешеву модель DeepSeek через OpenRouter. Я використовую `deepseek/deepseek-v4-flash`.

Ключ не публікуйте й не вставляйте в чати та репозиторії.

**Промт для нейронки:**

```text
Допоможи мені підключити OpenRouter до OpenCode як резервну модель.
Веди мене по одному кроку: 1) відкрити openrouter.ai/keys і створити ключ з лімітом кредитів; 2) поповнити баланс; 3) у терміналі виконати opencode providers login і обрати OpenRouter; 4) перевірити, що доступна модель openrouter/deepseek/deepseek-v4-flash.
Важливо: НЕ проси мене надсилати ключ у цей чат. Я вставлю його сам у вікно OpenCode.
Наприкінці запусти тестовий запит: opencode run -m openrouter/deepseek/deepseek-v4-flash "Скажи привіт".
```

*Якщо ви не знаєте, як підключити OpenRouter, або не хочете морочитись — дайте вашій нейронці цей промт.*

## Крок 4. Зробіть головну нейронку оркестратором

Головна нейронка (наприклад, Claude) викликає OpenCode командою `opencode run`. Перелік актуальних моделей дає `opencode models`.

**Промт для нейронки:**

```text
Працюй як оркестратор. Приймай мої задачі, розбивай їх на кроки й передавай виконання безкоштовним моделям OpenCode командою:
opencode run -m opencode/deepseek-v4.1-flash-free "<завдання>"
Якщо безкоштовна модель відповіла помилкою ліміту, повтори запит на резервній:
opencode run -m openrouter/deepseek/deepseek-v4-flash "<завдання>"
Результат кожного виконавця перевіряй сам, перш ніж сказати, що готово. Запиши це правило у файл CLAUDE.md (або AGENTS.md) у корені проєкту, щоб воно діяло в кожній новій сесії.
```

*Якщо ви не знаєте, як налаштувати таку схему, або не хочете морочитись — дайте вашій нейронці цей промт.*

Про файл-пам'ять, куди потрапляє це правило, я розповідав у статті [«Яку нейронку обрати у 2026»](/uk/blog/yak-obraty-nejronku).

## Крок 5. Перевірте схему на малому

1. Віддайте безкоштовній моделі одну нудну задачу: чернетку листа чи таблицю.
2. Перевірте результат самі.
3. Якщо модель відповіла помилкою ліміту, переконайтесь, що робота перейшла на резерв OpenRouter.

**Промт для нейронки:**

```text
Проведи перевірку схеми оркестратора. Віддай виконавцю з OpenCode задачу: «Напиши чернетку короткого листа клієнту про перенесення зустрічі».
Покажи мені: яку модель використано, який результат, що ти виправив після перевірки.
Потім навмисно виклич резервну модель openrouter/deepseek/deepseek-v4-flash з тією ж задачею і покажи, що вона теж відповідає.
```

*Якщо ви не знаєте, як це перевірити, або не хочете морочитись — дайте вашій нейронці цей промт.*

## Типові помилки

- **Віддати все без перевірки.** Безкоштовні моделі помиляються частіше. Дивіться на результат.
- **Прив'язатися до однієї моделі.** Їх список змінюється щомісяця, тримайте схему гнучкою.
- **Не поставити ліміт на ключ OpenRouter.** Без нього помилка в налаштуваннях може з'їсти баланс.
