# CRM Customs - Дизайн Система

## Концепція
Технічний інтерфейс з відчуттям програмного забезпечення, а не звичайного веб-сайту. Акцент на чіткій структурі, багато дрібних деталей та інтерактивних елементів.

## Кольорова Палітра

### Основні кольори
- **Фон:** Білий/світло-сірий (#FFFFFF, #F8F9FA)
- **Текст:** Чорний (#000000, #1A1A1A)
- **Акцент:** Жовтий (#FFD700) - для виділення важливих елементів, кнопок, активних станів

### Допоміжні кольори
- **Сірі тони:** #E5E5E5, #D4D4D4, #A3A3A3 - для рамок, ліній, неактивних елементів
- **Градації чорного:** #262626, #404040 - для підзаголовків та вторинного тексту

## Типографіка

### Шрифти
- **Основний:** Inter - для заголовків та основного тексту
- **Монофонт:** Space Mono - для технічних міток, номерів, кодів
- **Розміри:**
  - Заголовок H1: 3rem - 4rem (48px - 64px)
  - Заголовок H2: 2rem - 2.5rem (32px - 40px)
  - Заголовок H3: 1.5rem (24px)
  - Основний текст: 1rem - 1.125rem (16px - 18px)
  - Дрібний текст: 0.875rem (14px)
  - Монофонтні мітки: 0.75rem - 0.875rem (12px - 14px)

### Стилі тексту
- Жирний (font-bold, font-semibold) для заголовків
- Uppercase для технічних міток
- Letter-spacing для монофонтних елементів
- Line-height: 1.5-1.6 для читабельності

## Технічні Декоративні Елементи

### Рамки та Лінії
- Тонкі лінії (1px) чорного або сірого кольору
- Кутові рамки (L-подібні та рогові прикраси)
- Пунктирні лінії для з'єднання елементів
- Border-radius: 0px (прямі кути) або 4px-8px (ледь заокруглені)

### Мітки та Бейджі
- Прямокутні з монофонтом
- Фон: чорний з білим текстом або білий з чорним обведенням
- Розміщення: зверху-зліва або зверху-справа від блоків
- Приклади: "// LABEL", "[STATUS]", "01", "02"

### Сітка та Фон
- Тонка сіра сітка як фонова текстура
- Напівпрозорі накладання
- Геометричні патерни (лінії, точки)

## Геометричні Фігури

### Великі Акцентні Фігури
- **Жовте коло** - основна фігура для виділення центрального персонажа
- Розмір: 400px - 600px діаметр
- Позиція: за персонажем (z-index нижче)
- Ефекти: parallax при русі мишки

### Додаткові Форми
- Квадрати та прямокутники з обведенням
- Напівпрозорі накладання
- Рамки та бордюри

## Кнопки та Інтерактивні Елементи

### Кнопки Табів
- Квадратний номер (01, 02, 03) зліва
- Монофонтний текст
- Жовтий фон для активного стану
- Чорний текст на жовтому / Чорний текст на білому
- Hover: легка зміна кольору або масштабу

### CTA Кнопки
- Жовтий фон (#FFD700)
- Чорний текст
- Іконка стрілки праворуч
- Hover: зміна кольору на темніший жовтий або масштаб 1.05
- Padding: py-3 px-6 (великі кнопки)

### Навігаційні Кнопки (Карусель)
- Чорний фон або обведення
- Білі іконки
- Hover: жовтий акцент
- Розмір: 40px - 48px квадрат

## Інтерактивність та Анімації

### Hover Ефекти
- Зміна кольору (transition-colors duration-300)
- Легкий масштаб (scale-105)
- Зміна прозорості
- Підсвітка жовтим акцентом

### Parallax
- Рух великого жовтого кола при русі мишки
- Зсув центрального персонажа
- Легкі зсуви декоративних елементів

### Анімації Появи
- Fade-in з затримкою (stagger)
- Slide-in зліва/справа
- Scale-in для карток
- Transition duration: 300ms - 600ms

## Компонентні Патерни

### Картки Кейсів
- Прямокутна форма з рамкою
- Зображення вгорі
- Іконка компанії (кругла, 48px)
- Структуровані блоки інформації
- Hover: легке підняття (shadow-lg)

### Інформаційні Блоки
- Білий або світло-сірий фон
- Чорна рамка (1px)
- Жовтий акцент зліва або зверху
- Монофонтна мітка
- Padding: 20px - 32px

### Карусель
- Горизонтальний скрол
- Навігаційні стрілки з боків
- Точкові індикатори внизу
- Жовтий активний індикатор
- Gap між картками: 24px

## Композиція та Лейаут

### Сітка
- CSS Grid для основних лейаутів
- Flexbox для вирівнювання всередині блоків
- Gap: 16px, 24px, 32px між елементами

### Відступи
- Section padding: py-16 або py-20 (64px - 80px)
- Container max-width: 1400px - 1600px
- Внутрішні відступи: 16px, 24px, 32px

### Зображення та Медіа
- Центральний персонаж: прозорий PNG, великий розмір
- Фото команди: з технічними рамками
- Зображення кейсів: 16:9 або 4:3 співвідношення

## Технічні Особливості

### Responsive Design
- Mobile-first підхід
- Breakpoints: md:768px, lg:1024px, xl:1280px
- Stack вертикально на мобільних
- Горизонтальні лейаути на десктопі

### Доступність
- Alt текст для всіх зображень
- Semantic HTML (header, main, section)
- Keyboard navigation
- Достатній контраст (чорний на білому, білий на чорному)

### Оптимізація
- Lazy loading для зображень
- CSS transitions замість JavaScript де можливо
- Optimized з-index для layering

## Стиль Написання Контенту

### Мова
- Українська мова для всього контенту
- Професійний але доступний тон
- Короткі чіткі речення

### Структура
- Чіткі заголовки з нумерацією
- Списки з галочками (✓) або номерами (01, 02)
- Виділення ключових фраз
- Розділення на блоки проблема/рішення/результат

## Не Використовувати

❌ Фіолетовий колір (якщо не запитано явно)
❌ Градієнти (тільки якщо явно потрібні)
❌ Емоджі замість іконок
❌ Занадто багато різних кольорів (макс 5)
❌ Більше 2 сімейств шрифтів
❌ Абстрактні декоративні форми без мети
❌ Складні SVG ілюстрації (використовувати іконки)

## Резюме

Дизайн CRM Customs - це мінімалістичний технічний інтерфейс з акцентом на функціональність та деталі. Використання чорно-білої палітри з жовтими акцентами, монофонтних міток, тонких ліній та геометричних форм створює відчуття професійного програмного забезпечення. Інтерактивні елементи та parallax ефекти додають динаміку, а чітка структура інформації забезпечує легке сприйняття.
