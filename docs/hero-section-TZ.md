# Технічне завдання: Hero-секція для CRM Customs

## 🎯 Загальна концепція

Створити hero-секцію головної сторінки в стилі **tech/product interface** (інтерфейс програми, а не просто сайт) зі **світлим фоном** та максимальною інтерактивністю.

---

## 🎨 Колірна схема

### Основні кольори:
```css
--white: #FFFFFF;           /* Основний фон */
--light-gray: #F5F5F5;      /* Додатковий фон */
--black: #000000;           /* Основний текст */
--yellow: #FFD700;          /* Акцентний колір */
--gray: #666666;            /* Вторинний текст */
--border-color: rgba(0, 0, 0, 0.1);  /* Тонкі лінії та рамки */
```

### Використання:
- **Фон:** білий (#FFFFFF) або світло-сірий (#F5F5F5)
- **Текст:** чорний (#000000) для заголовків, сірий (#666666) для тексту
- **Акценти:** жовтий (#FFD700) для CTA, важливих елементів, іконок
- **UI елементи:** чорний з низькою прозорістю для ліній та рамок


---

#### 4.2 Floating particles

**Параметри:**
- Кількість: 20-30 частинок
- Розмір: 2-3px (крапки)
- Колір: жовтий або чорний з прозорістю
- Позиції: випадкові по всьому екрану

**Анімація:**
- Повільний рух (float) 10-20 секунд
- Різні траєкторії для кожної
- Зміна opacity: 0.3 → 0.8 → 0.3

**JS generation:**
```javascript
for (let i = 0; i < 30; i++) {
  const particle = document.createElement('div');
  particle.style.left = Math.random() * 100 + '%';
  particle.style.top = Math.random() * 100 + '%';
  particle.style.animationDelay = Math.random() * 15 + 's';
  // append to container
}
```

## 💫 Анімації (загальні)

### При завантаженні сторінки:

**Послідовність (staggered animations):**
1. Nav bar — fade in down (0s)
2. Hero left content — fade in left (0.3s)
3. Hero right (персонаж) — fade in right (0.5s)
4. UI frames — fade in (1s, 1.2s, 1.4s)
5. UI text labels — fade in (1.3s, 1.5s, 1.7s)
6. Connecting lines — draw (1.6s, 1.8s)
7. Recent cases — fade in up (1s)

**Тривалість анімацій:** 0.8-1s з ease-out

---

### Інтерактивні анімації:

**Hover кнопок:**
- Transform: translateY(-2px)
- Box-shadow: збільшення
- Duration: 300ms

**Hover персонажа:**
- Transform: scale(1.05)
- Duration: 300ms

**Mouse move parallax:**
- Персонаж: ±15px
- Жовте коло: ±7px (0.5x)
- Particles: ±5px (0.3x)

**Scroll parallax (опційно):**
- При скролі вниз елементи рухаються з різною швидкістю
